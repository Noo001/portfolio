# Портфолио-лендинг Андрея Ефремцева

Лендинг-презентация с формой обратной связи и AI-подсказкой. Тестовое задание для вакансии Fullstack-разработчик.

## 🌐 Демо

- **Живой сайт:** https://noo001.github.io/portfolio/
- **Backend API (Render):** https://portfolio-backend.onrender.com

- **Frontend:** http://localhost:4200 (локально)
- **Backend:** http://localhost:3000 (локально)

## 📦 Стек технологий

| Технология | Назначение |
|------------|------------|
| Angular 21 | Frontend (Standalone компоненты, Signals) |
| TypeScript | Типизация на фронтенде |
| SCSS | Стилизация, адаптив |
| Node.js + Express | Backend API |
| Nodemailer | Отправка писем (демо-режим → лог-файл) |

## 🛠️ Установка и запуск

### Требования
- Node.js 18+
- Angular CLI 21

### 1. Установка зависимостей

```bash
# Бэкенд
cd backend
npm i
npm start

# Фронтенд (в новом терминале)
cd frontend
npm i
ng s
```
Приложение откроется на ```http://localhost:4200```

## 📧 Форма обратной связи

**Поля:**
- Имя
- Телефон
- Email
- Комментарий

**Валидация:**
- Все поля обязательны
- Email проверяется на корректность

**Отправка:**
- Данные уходят на бэкенд `/api/send-message`
- Сообщение сохраняется в файл `backend/messages.log`

> Из-за ограничений Google для пользователей России реальная отправка писем заменена на сохранение в лог-файл. Код готов к переключению на реальный SMTP.

**Состояния формы:**
- `loading` — кнопка блокируется, текст меняется
- `success` — зелёное сообщение об успехе
- `error` — красное сообщение об ошибке

## 🤖 AI-интеграция

При нажатии кнопки **«✨ AI-подсказка»** текст комментария «улучшается»:

- Добавляется вежливое обращение
- Исправляется пунктуация
- Добавляется пометка о демо-режиме

> Реальная интеграция с OpenAI API невозможна из-за санкционных ограничений. Реализована демо-заглушка, демонстрирующая подход к интеграции. Для перехода на реальный API достаточно заменить `aiService.js` и добавить `OPENAI_API_KEY` в `.env`.
